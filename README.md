# 📖 Project Overview

TechNova is a modern and responsive business landing page developed using **HTML5, CSS3, and JavaScript**. The project demonstrates the fundamentals of front-end web development by creating a clean, visually appealing, and user-friendly website that adapts seamlessly to different screen sizes.

The website is designed to simulate a professional business website with multiple sections such as Home, About, Services, Why Choose Us, Statistics, Portfolio, Team Members, Testimonials, Contact, and Footer. It follows modern UI/UX principles to provide an engaging user experience.

This project was created as part of a **Frontend Web Developer Internship** to demonstrate responsive web design, semantic HTML structure, CSS styling, JavaScript interactivity, and project documentation skills.
